// rock-paper-scissors-cpp
//A simple Rock Paper Scissors game created using Cpp.

A simple Rock Paper Scissors game created using C++.

## How it works.
- I used an array to store `rock`, `paper`, and `scissor`.
- I used the random function to automatically select a choice for the computer.
- The computer's choice is compared with the user's input.
- `if-else` statements are used to determine the winner.

## Concepts Used.

- C++ 
- Arrays
- User Input
- Random Number Generation
- if-else Statements
